SyncMark extension settings

Choose which self-hosted bookmark service this extension talks to.

Point this extension at your SyncMark server — the same address you use to open it in a browser tab. Sign in (or run first-time setup) from the toolbar popup, not here.

Connect to a self-hosted Linkwarden instance over HTTP or HTTPS — a LAN address like http://192.168.1.10:3000 works too. Sign in with your account, or paste a pre-generated Access Token from Linkwarden's Settings → Access Tokens (recommended — it avoids storing your password).

Connect to a self-hosted Karakeep instance over HTTP or HTTPS — a LAN address like http://192.168.1.10:3000 works too. Karakeep's API only supports API keys (no username/password) — generate one from Settings → API Keys.

Bookmarks bar

Pin one folder/collection/list to a slim bar SyncMark adds under the address bar on every page — a self-hosted stand-in for the browser's native bookmarks bar, synced from whichever service is connected above. Already-open tabs pick up changes automatically.
