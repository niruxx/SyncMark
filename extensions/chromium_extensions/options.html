SyncMark extension settings

Point this extension at your SyncMark server — the same address you use to open it in a browser tab.

This extension talks directly to your SyncMark server's API using your existing sign-in — nothing is sent anywhere else. If your server isn't reachable at localhost, make sure the address above (including port) matches exactly.

Bookmarks bar

Pin one folder to a slim bar SyncMark adds under the address bar on every page — a self-hosted stand-in for the browser's native bookmarks bar. Already-open tabs pick up changes automatically.
