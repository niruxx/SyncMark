How to use SyncMark

A quick tour, plus step-by-step setup for syncing your contacts and calendar to a phone or computer.

Using the app

  1. Bookmarks — add one manually with "Add bookmark", organize them into folders from the sidebar, drag to reorder or move between folders, and search or sort from the toolbar. Import an existing browser export from Settings → Import bookmarks, below.
  2. Contacts — works the same way for people: add, edit, delete, and star favorites. Use the checkboxes to multi-select several contacts for a bulk action (favorite, export, or delete), and import/export .vcf or .csv files from the toolbar or Settings.
  3. Calendar — shows a month view. Click a date to open that day's events in the side panel (the calendar shrinks to make room); right-click a date or an event for a quick Add/Edit/Remove menu without opening the full editor.
  4. Account — click your name (top right) to reach account settings or sign out from anywhere.
  5. Settings (this page) — theme, session length, import/export for all three tabs, sync setup, and library stats.

Setting up sync on your devices

Contacts and Calendar both sync over the same CardDAV/CalDAV server address (shown further down this page, under Contacts sync) using your regular SyncMark username and password — no separate sync password to manage. Expand your device below.

iOS (iPhone / iPad)
  1. Open the Settings app on your device.
  2. For contacts: Contacts → Accounts → Add Account → Other → Add CardDAV Account. For calendar: Calendar → Accounts → Add Account → Other → Add CalDAV Account.
  3. Server: paste the address from "Server address" below (e.g. https://your-server/dav/).
  4. Username / Password: your SyncMark login.
  5. Tap Next, then Save — iOS verifies the account and starts syncing (give it a few seconds the first time).
Android
  1. Install DAVx5 (F-Droid or Play Store) — stock Android has no built-in CardDAV/CalDAV setup.
  2. Open DAVx5 → tap + → Login with URL and username.
  3. Base URL: the server address below. Username / password: your SyncMark login.
  4. DAVx5 discovers both the address book and calendar automatically — enable the ones you want to sync.
  5. In Android's own Settings → Accounts, confirm contact and calendar sync are turned on for the DAVx5 account, and that your Contacts/Calendar apps are set to display it.
Linux
  1. GNOME: Settings → Online Accounts → Add Account → CardDAV / CalDAV, then enter the server address and your SyncMark login. GNOME Contacts, GNOME Calendar, and Evolution pick it up automatically.
  2. KDE: System Settings → Online Accounts (or add a CardDAV/CalDAV resource directly from Kontact/KAddressBook/KOrganizer's account settings) with the same address and login.
  3. Any distro, via Thunderbird: Address Book → File → New → CardDAV Address Book; Calendar → New Calendar → On the Network → format CalDAV. Same server address and login either way.
Windows
  1. Windows' built-in Mail/Calendar/People apps only support Exchange, Google, iCloud, and Outlook.com accounts — not a generic CardDAV/CalDAV server — so they can't point at SyncMark directly.
  2. Install Thunderbird instead: Address Book → File → New → CardDAV Address Book; Calendar → New Calendar → On the Network → format CalDAV.
  3. Server address and login: same as below.
  4. Or skip sync entirely and just use the Contacts/Calendar tabs in the browser — nothing extra needed for single-device use.

Contacts sync (CardDAV)

Point your phone's Contacts app at this address to sync SyncMark contacts in both directions — add, edit, or delete a contact on your phone and it shows up here, and vice versa. Sign in with your regular SyncMark username and password.

iOS: Settings → Contacts → Accounts → Add Account → Other → Add CardDAV Account — paste the address above as the server, and your SyncMark username/password.
Android: stock Android has no built-in CardDAV setup — install the free DAVx5 app, add an account with the address above, then enable contact sync for it in your phone's Accounts settings.

Calendar sync (CalDAV)

Uses the same server address as Contacts sync above — one address and one login drive both. Point your phone's Calendar app at it to sync SyncMark events in both directions.

iOS: Settings → Calendar → Accounts → Add Account → Other → Add CalDAV Account — same server address and SyncMark username/password as Contacts sync.
Android: the same DAVx5 account used for contacts also handles calendar sync — enable it in your phone's Accounts settings.

About

Keyboard shortcuts (on the Bookmarks page): / to search, n to add a bookmark, Esc to close dialogs.
